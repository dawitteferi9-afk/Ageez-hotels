# Auth Layer (Auth.js)

Session/auth configuration and role-based access helpers for staff roles:
OWNER/ADMIN, MANAGER, FRONT_DESK, HOUSEKEEPING, MAINTENANCE. Guest checkout
requires no account (v0.1 decision — guest accounts out of scope). Also the
home for the future distinction between hotel-level ADMIN and Ageez
platform-level admin (see src/app/(platform-admin)/README.md). Not
implemented yet — reserved for M4 alongside the management dashboard.
