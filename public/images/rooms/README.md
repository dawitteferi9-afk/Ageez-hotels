# Room Photography (Guest Experience Enhancement — Phase D)

These directories are placeholders (`.gitkeep`) reserving the intended
local structure for real Ageez Grand Hotel room photography, once
supplied separately. No image files exist here yet, and none are
fabricated, downloaded, or linked externally by this phase.

To add photography for a room type: drop the file(s) into its directory
below, then set that room type's `hero`/`gallery` paths in
`src/lib/guest/roomPhotography.ts`. No other code change is required —
see that file's own module comment for the full "future switch" mechanism.

- `standard-king/`
- `deluxe-twin/`
- `executive-room/`
- `family-suite/`
- `presidential-suite/`
